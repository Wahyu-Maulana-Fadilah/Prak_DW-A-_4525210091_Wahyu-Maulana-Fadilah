# Rangkuman Perubahan, Masalah dan Solusi Tugas 2

## Perubahan, Masalah dan Solusi
Pada kodingan HTML profil kampus ini, kodenya dibuat terstruktur menggunakan tag semantik seperti header, nav, dan section. Isinya cukup lengkap, mulai dari daftar fakultas menggunakan unordered list, alur pendaftaran dengan ordered list, detail lokasi kampus memakai description list, hingga link navigasi dan kontak sosial media. Masalah yang dihadapi sebenarnya bukan dari kesalahan kodingan, melainkan kebutuhan untuk menampilkan aset visual berupa logo dan foto gedung kampus di dalam halaman web. Solusinya adalah menggunakan tag img yang dilengkapi atribut src untuk memanggil path file gambarnya, serta atribut alt, width, dan title agar gambarnya bisa muncul dengan rapi dan ukurannya pas. Selain itu, sedikit penyesuaian juga dilakukan dengan merapikan posisi tag link di bagian kontak dan mengubah lang="id" sesuai bahasa konten. Hasilnya, halaman HTML profil kampus ini jadi kelihatan lebih menarik, informatif, dan kodenya tetap rapi saat dibuka di browser.
